# RepoSathi AI 🧭

**A local-first open-source onboarding assistant that helps newcomers understand a repository and identify a small, useful first contribution.**

## The problem
New contributors often struggle to understand an unfamiliar codebase, find a beginner-sized task, or know what to check before contacting a maintainer. Generic chatbots may require paid API credits and sending project context to a third-party service.

## What RepoSathi does
- Accepts a README or repository overview pasted by the user.
- Uses a locally running open-weight model through Ollama to explain the project and suggest a grounded first task.
- Adapts guidance to a beginner, someone with basic skills, or an intermediate contributor.
- Gives actionable steps, risks/checks, and questions to ask a maintainer.
- Lets the user download the generated guide as Markdown.
- Sends no prompt to a hosted AI API; the app has no account system or analytics.

## Open-source AI is core
The analysis is generated by an open-weight model served locally by Ollama. Without that model, the main analysis workflow does not run. This keeps API cost at zero and lets users keep pasted repository context on their own machine. Model weights and licenses vary, so users should review the chosen model's license and hardware requirements.

## Run locally

1. Install Python 3.10+.
2. Install [Ollama](https://ollama.com/).
3. Download a model. Example:

   ```bash
   ollama pull qwen2.5:3b
   ```

   A smaller model may work better on lower-memory machines. The model download requires internet once; inference runs locally afterward.

4. Create and activate a virtual environment:

   **Windows PowerShell**
   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   streamlit run app.py
   ```

   **macOS/Linux**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   streamlit run app.py
   ```

5. Open the local URL shown by Streamlit, usually `http://localhost:8501`.
6. Paste a README, choose a goal and skill level, then click **Analyze with local open model**.

Ollama should be available at `http://localhost:11434`. Set `OLLAMA_URL` or `OLLAMA_MODEL` environment variables to override defaults.

## Quick smoke test
- With Ollama running and the selected model installed, click **Check local AI** and confirm the model appears.
- Paste the included TinyTasks sample README and run the analysis.
- Confirm a guide appears and the Markdown download works.
- Stop Ollama and retry: the app should show a helpful connection error instead of crashing.

## Architecture

```text
User-pasted README/context
          |
          v
Streamlit UI (app.py)
          |
          v
Prompt builder + grounded-analysis instructions
          |
          v
Ollama local HTTP API -> open-weight model
          |
          v
Markdown guidance -> display / download
```

## Limitations
- The prototype analyzes only the context pasted by the user. It does not claim to inspect the full GitHub repository automatically.
- Model output can be wrong. Verify suggested tasks against the real files, tests, and contribution guide.
- Model performance depends on hardware and model size.
- The first model download needs internet; inference is local after download.

## Responsible use
Do not paste secrets, private source code, or personal data. Respect each repository's license and `CONTRIBUTING.md`. Make small, tested contributions and ask maintainers before large changes.
